# VenueSync

VenueSync is a smart venue booking system for KLE Technological University built with the MERN stack.

## MVP Scope

This repository now targets the review-2 MVP:

- JWT auth with student, teacher, and admin roles
- Protected dashboards with role-based redirects
- Venue discovery, availability checks, and booking requests
- Admin approve/reject workflow with remarks and notifications
- Teal and blue institutional UI styling

## Tech Stack

- Frontend: React, Vite, Tailwind CSS, React Router DOM, Axios
- Backend: Node.js, Express.js, MongoDB, Mongoose
- Auth: JWT, bcrypt
- State: React Context API

## Run

1. Install dependencies in both `backend` and `frontend`.
2. Create `.env` files from the sample variables in the codebase.
3. Start the backend server.
4. Start the frontend Vite app.
